# Environment Setup & OASis Database Configuration Guide

This guide covers the initial system setup, Conda environment lockfile generation, reference database downloading, and verification tests for the **BioPhi / OASis** antibody evaluation suite.

---

## Part 1: Conda Environment Setup & Reproducibility Lock

Follow these steps to build and export a fully reproducible Conda environment for BioPhi:

```bash
# 1. Create the environment from the repository configuration file
conda env create -f environment.yml

# 2. Activate the biophi environment
conda activate biophi

# 3. Export a locked environment file for exact build reproducibility
mkdir -p checkpoint 
conda env export > checkpoint/biophi-lock.yml
```

---

## Part 2: OASis Database Download & Configuration

To enable full OASis humanness evaluation, download and unpack the reference 9-mer frequency database (~22 GB uncompressed):

```bash
# 1. Create directory and navigate into the database folder
mkdir -p db
cd db

# 2. Download the official OASis 9-mers database archive from Zenodo
wget https://zenodo.org/record/5164685/files/OASis_9mers_v1.db.gz

# 3. Decompress the database file (~22 GB)
gunzip OASis_9mers_v1.db.gz

# 4. Return to the project root and export the database path variable
cd ..
export OASIS_DB_PATH=$PWD/db/OASis_9mers_v1.db
```

---

## Part 3: Environment Verification & Basic Sanity Tests

Verify that `abnumber` antibody sequence parsing and the `biophi` CLI binary are properly configured and operational:

# Therapeutic Antibody Immunogenicity Risk Assessment Workflow (OKT3)

This workflow integrates **BioPhi (OASis) Humanness Evaluation** and the **IEDB MHC-II Prediction API** to perform an end-to-end immunogenicity risk assessment for therapeutic antibodies (using OKT3 as a representative benchmark).

---

## 1. Environment and Variable Setup

Set the project root directory environment variable and create a dedicated working directory for testing:

```bash
# Define the root directory path
export DIR_immunogenicity_risk=$PWD

# Create and switch to the test execution directory
mkdir -p testrun
cd testrun
```

---

## 2. FASTA Sequence Preparation

Extract the heavy and light chain variable regions for OKT3 (Muromonab-CD3) from the RCSB Protein Data Bank (PDB entries [1SY6](https://www.rcsb.org/structure/1SY6) or [1N8Z](https://www.rcsb.org/structure/1N8Z)) and write them into a standardized FASTA file:

```bash
# Create FASTA input file containing heavy (okt3_heavy) and light (okt3_light) chains
cat << 'EOF' > okt3.fa
>okt3_heavy
QVQLQQSGAELARPGASVKLSCKASGYTFTRYTMHWVKQRPGQGLEWIGYINPSRGYTNYNQKFKDKATLTDKSSSTAYMQLSSLTSEDSAVYYCARYYDDHYCLDYWGQGTTLTVSS
>okt3_light
DIQMTQTTSSLSASLGDRVTISCRASQDIRNYLNWYQQKPDGTVKLLIYYTSRLHSGVPSRFSGSGSGTDYSLTISNLEQEDIATYFCQQGNTLPWTFGGGTKLEIK
EOF
```

---

## 3. BioPhi OASis Humanness Evaluation

Evaluate the antibody humanness score by scanning 9-mer sliding windows against the Observed Antibody Space (OAS) database using BioPhi CLI, exporting detailed results to an Excel spreadsheet:

```bash
# Run BioPhi OASis evaluation and log stdout to biophi.log
biophi oasis okt3.fa \
  --oasis-db $DIR_immunogenicity_risk/db/OASis_9mers_v1.db \
  --output oasis_okt3.xlsx
```

---

## 4. Downstream Risk Analysis & Epitope Prediction

Execute custom Python parsing scripts to compute global humanness scores, quantify non-human 9-mer hotspots, and query the IEDB MHC-II API for high-risk T-cell epitope prediction (Percentile Rank < 2.0%):

```bash
# 1. Parse and print global BioPhi humanness scores (OAS Percentile / Identity)
python $DIR_immunogenicity_risk/app/biophi_humanness.py oasis_okt3.xlsx | tee biophi_humanness.log

# 2. Count non-human 9-mer peptide segments (OAS occurrence frequency = 0 or below threshold)
python $DIR_immunogenicity_risk/app/biophi_counts.py oasis_okt3.xlsx | tee biophi_counts.log

# 3. Query IEDB MHC-II API to predict and filter high-risk T-cell epitopes (Rank < 2.0%)
python $DIR_immunogenicity_risk/app/iedb_mhcii.py okt3.fa | tee iedb_mhcii.log
```

---

## 📊 Summary of Expected Outputs

| Output File Name | Description |

| `oasis_okt3.xlsx` | Excel report generated by BioPhi OASis containing per-peptide 9-mer OAS frequencies |
